Route Structure

DinGaming uses client-side routing with the following primary routes:

  • / - Homepage with featured games and promotions
  • /search - Search interface for game discovery
  • /categories - Browse games by category
  • /deals - Special offers and promotions
  • /club - User account and membership section
  • /login - Authentication page
  • /register - User registration
Technical

Technology Stack

Framework React with Vite bundler
Routing Client-side SPA routing
Typography Google Fonts (DM Sans, Playfair Display)
Analytics Flock analytics platform

Architecture Highlights

  • Single Page Application: All content loaded client-side with no server-side rendering
  • Dynamic Routing: 7+ primary routes handling browsing, search, account, and authentication flows
  • Performance: Vite for fast build times and optimized module bundling
  • Analytics Integration: Flock platform for tracking user behavior and engagement

Key Features

  • Advanced game search with filtering and sorting
  • Category-based browsing for game discovery
  • Real-time deals and promotions display
  • User authentication and account management
  • Club membership system for exclusive benefits
  • Multi-platform game key delivery (Steam, PlayStation, Xbox, Nintendo, Epic Games)

Frontend Considerations

  • Responsive design for desktop and mobile users
  • Font loading strategy using Google Fonts CDN
  • Client-side state management for user session and cart data
  • Event tracking for purchase funnels and user engagement
  • No sitemap.xml (client-side routing not conducive to traditional SEO)
